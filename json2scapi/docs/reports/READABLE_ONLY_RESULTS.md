# Readable 单路径与适配规则补全（2026-10-23）

## 生产契约

默认及唯一生产风格为 readable。`ir2code.generate(..., style="faithful")` 和 CLI faithful 选项不再可用。`build_corpus.py` 不生成/构建 faithful，不进行 faithful/readable 对账，只依据 readable 有效构建及独立参考验收导出。历史 emitter 仅冻结于 `tests/_legacy_emitter.py` 作为回归 oracle，不被生产模块引用。

独立参考仍必需；测量不可用为 provisional，明确不匹配为 rejected。没有降低体积、面积、bbox、差集、IoU 或 CD 阈值。历史批次不覆盖。

## 修正

- 局部平面 z 残差最多 1e-4 mm；允许范围内投影并记录来源，超出拒绝。
- 对微小轴长度舍入做有界归一化，不改变方向；非正交或非右手 frame 拒绝。
- 无 taper 的有符号双侧拉伸按区间归一化，覆盖负侧和零侧；同侧退化为单向，跨零保留双侧。保留源距离及区间追溯。带 taper 的此类归一化不猜测。
- 独立参考在本地适配层恢复原始笛卡尔 frame 和 profile anchor，解决官方 arctan 象限丢失；官方 tracked 源文件未修改。
- IR Schema/语义检查、单文件代码入口、语料目录约定和测试同步更新。
