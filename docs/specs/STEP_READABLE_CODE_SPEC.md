# STEP2Code 结构化代码规范 v1

- 规范标识：`step-readable-v1`。
- 更新日期：2026-10-26。
- 状态：已启用解析直线棱柱及经验证的完整旋转子集；实现和验证边界见第 13 节。
- 当前实现：`step2scapi 0.4.0`、`analytic-prism-revolution-csg-v4`；纯拉伸使用 `step-prism-emitter-v1`，混合/旋转使用 `step-composite-emitter-v1`。拉伸复用 readable v3 的 IR 准备与安全草图构建。旧产物仍按原版本解释。

本规范约束“STEP 边界几何 → 重建计划 → 独立 SCAPI 代码”的结构、参数语义及验收证据。它不是新的 CAD IR 版本，也不修改 [DeepCAD readable v3 契约](../../../json2scapi/docs/specs/READABLE_CODE_SPEC.md)。

文中的“必须 / 不得”是启用本规范时的要求；“允许”是通过能力和验证门槛后的可选能力，不表示当前转换器已经支持。

## 1. 目标与真实性

1. 生成默认参数下与源 STEP 对应的可执行几何模型，保留物理尺寸和世界位置。
2. 使用可追溯的重建操作组织代码，明确它们是算法推断的方案。
3. 将有意义的形状尺寸与定位数据分开表达；每个公开参数有来源和编辑策略。
4. 代码可独立导入及重复调用 `build()`；代码结构便于人工阅读和参数编辑测试。

几何等价只能证明重建结果满足所声明的验收协议，不能证明恢复了原始设计意图、约束、特征树或装配关系。无独立来源证据时，必须记录 `history_recovered=false`。不得把源面编号称为源特征编号，也不得从重复形状直接推断原始阵列。

## 2. 处理阶段和职责

```text
STEP 导入和单位处理
  → 源实体/面/边索引
  → 候选几何识别与证据
  → 明确的重建操作依赖图
  → 参数、坐标架及模板规划
  → IR 几何准备
  → SCAPI emitter
  → 实际 build / 导出回读
  → 原始参考的几何验收
  → 参数编辑、覆盖范围及装配结构的独立评价
```

- **识别层**负责解析曲线、曲面、孔归属、候选重建及几何证据；不得以 bbox 或体积相等单独确认重建。
- **计划层**决定重建操作、执行依赖、命名、参数关系和模板复用；不得为缩短代码而删除或改变布尔语义。
- **准备层**执行有界且有记录的端点统一、坐标变换和派生几何核查。
- **emitter**只翻译已确定的计划。不得在生成期间重新识别孔、猜测阵列、猜测设计约束或搜索其他建模方案。
- **验收层**读取源参考和实际执行结果，不以脚本自报的体积或 `BODIES` 代替真实返回值。

当前 IR 只支持的操作必须显式列入能力清单。新操作需要识别、重建计划/IR、emitter、运行时及验证链路同时支持；不得仅输出一个尚无实现的操作名称。

## 3. 独立代码的程序层次

默认顺序如下：

1. 模块说明与 `import simplecadapi as scad`。
2. 按重建特征分组的形状参数、按实体/实例分组的定位参数；`BODIES = None`。
3. `make_profile_01(...)` 等草图函数：显式创建局部轮廓，返回有序 face 元组。
4. `apply_feature_01(bodies, ...)` 等操作函数：创建工具几何，按计划执行 new / join / cut 等已支持的操作。
5. 必要时定义 `make_body_01(...)` 或命名清晰的同构实体工厂，封装一个完整实体的重建步骤。
6. `build()`：读取顶部参数、显式调用操作或实体工厂、完成定位、写入 `BODIES` 并返回模型。
7. 实际使用到的局部辅助函数，如 `_add_closed_polyline()`、`_as_model()`。

`make_body_*()` 是可选层；单一简单拉伸无需增加只有一次转发的包装函数。`apply_feature_*()` 必须使用可识别的几何操作，不得变成通用指令执行器。

### 3.1 运行时约束

- 生成脚本只导入 `simplecadapi`，不依赖项目模块、IR、外部 STEP、BREP、隐藏文件或网络。
- 不得嵌入 STEP/BREP/base64，不得把源码字符串交给 `eval` / `exec`，不得使用动态导入或按操作名称动态分发的解释器。
- 顶部参数在调用 `build()` 时读取，以显式关键字参数传递；不得在函数定义的默认值中提前绑定尺寸。
- 每次调用创建新的可变几何；不得缓存并复用可变 sketch、face、solid 或 assembly。
- `build()` 返回真实 Solid / Part / Assembly 或受支持的实际结果包装；无实体结果必须报错。
- `BODIES` 保存最终实体集合。v1 默认保存世界坐标下的实体；若以装配包装，使用一致的 placement 表达，禁止重复应用变换。

### 3.2 build 的表达

`build()` 负责组装重建过程，不负责曲线识别、参数搜索、度量计算或几何修复。参数关联、操作顺序和实体归属必须从源码或旁置元数据中直接追踪。

允许对具有同一明确工厂的实例列表做循环，但列表使用命名字段并保留逐实例参数来源。循环体必须直接调用已知工厂；不得以 opcode、任意节点图或不透明的坐标数组解释整个模型。

## 4. 重建操作、命名和确定性

### 4.1 分组与顺序

- 一个函数对应一个可说明的重建操作，或保持原子布尔语义的连续操作组。
- 无源特征历史时，以重建依赖图为执行依据，不以源面遍历顺序冒充历史。
- 布尔操作的对象、工具集合、顺序和多 region 归属必须明确。join / cut 等操作缺少目标实体时必须报错，不得退化为 new。
- 一个源实体可以对应多个重建操作；多个源实体也可在有记录的重建方案中参与一个操作。必须保存多对多覆盖映射，不能仅用函数数或输出 solid 数证明覆盖完整。
- 存在不支持的源实体时，整个 case 不得获得完整重建通过状态。诊断用的部分产物必须标记 `partial`，不能混入完整通过语料。

### 4.2 命名

主要名称采用稳定的 `FEATURE_01_*`、`BODY_01_*`、`make_profile_01`、`apply_feature_01`。模板可使用经确认的几何类别名称，但不得猜测“螺钉”“轴承”等零件用途。

随机 STEP ID、导入器内部地址和长文档 ID 只进入来源映射，不作为主要函数或参数名称。孔和外轮廓按确定性顺序编号，不因数值相等而共用编号。

### 4.3 确定性与候选选择

必须保证同一输入内容、配置和依赖版本下，生成代码确定；运行时间等非确定信息仅进入运行报告。

候选排序应使用记录在案的几何与复杂度规则，再使用明确的并列规则。拉伸路径的类别为解析端面棱柱：按端面面积降序，再按平面位置、平面法向及导入面序号排序。导入器面序号可作最后的同输入消歧，不能宣称它在重新导出的 STEP 中稳定。

若为排序使用容差量化键，不得把量化值写回几何。候选的接受证据、拒绝原因和最终选择规则必须可审计；多个等价方案的选择不表示其中某一个是原始历史。

## 5. 参数来源与编辑策略

每个公开参数至少记录以下信息：

| 字段 | 要求 |
|---|---|
| `value`、`units` | 默认值和物理量；方向向量为无量纲 |
| `quantity` | 长度、角度、位置、方向等语义 |
| `origin_kind` | `measured` / `derived` / `inferred` |
| `edit_policy` | `independent` / `dependent` / `fixed` |
| `bindings` | 所控制的重建操作和 IR 字段 |
| `evidence_refs` | 源面/边、识别证据及数值核查的引用 |
| `expression` | dependent 参数的明确依赖表达；非 dependent 可为空 |

这些是不同维度：一个经解析计算得到的拉伸距离，可以作为重建方案中的独立编辑参数，但不能因此宣称它是原模型的独立设计尺寸。

- 优先公开半径、长度、角度、孔位置等有明确几何意义的参数；不得把所有浮点数机械提升为顶部常量。
- 默认独立参数之间不因数值相等而合并。设计参数共享必须有明确依据或显式选项，并记录它影响的全部位置。
- `dependent` 参数不得同时作为另一个互不受控的独立入口，避免不一致的中心、半径和端点。
- `fixed` 数据仍需保留精确值和来源；默认不纳入参数编辑能力声明。
- 不为未知关系编造置信概率、设计约束或参数范围。

### 5.1 拉伸距离的证据

优先使用可验证的平行端面间距、对应边或侧面投影恢复距离。`V / A` 允许用来构造候选，但须标记 `origin_kind=derived` 并记录公式与输入。

若距离由源体积计算，则候选体积相等不是独立识别证据。候选仍必须通过空间重合证据，例如 bbox 过滤后的双向 Cut 对称差核查。生成后仍需执行 CD、IoU、V 验收，以检查代码和导出链路是否忠实实现了候选。

### 5.2 圆与圆弧

圆半径可独立参数化。圆弧必须先核查三点、方向、中心及半径的一致性，再决定是否暴露半径参数。端点共享关系必须显式保留；不得在编辑时使相邻线弧意外脱开。

没有足够证据支持参数关联时，保持明确坐标和受限编辑策略，不为了增加“参数数量”编造依赖。

## 6. 局部形状与定位

形状尺寸、局部草图坐标、实体/实例定位分别组织。定位参数示例为 `BODY_01_ORIGIN_MM`、`BODY_01_X_AXIS`，长度与无量纲方向不得混用单位。

- 记录源坐标架、选择后的局部坐标架及局部到世界的变换。
- 局部坐标架必须右手、正交、单位化；允许的数值调整有容差、原值和记录。
- 可以在创建草图平面时将定位烘焙进世界坐标，也可以使用已验证的 SCAPI 定位能力；一个变换只能应用一次。
- 不得分别缩放源几何和生成几何以掩盖重建尺寸错误。
- 坐标架规范化仅改变表达，不得改变实际世界几何；需要通过几何复核。

模板实例可以共用结构，但位置和朝向保留独立记录。源 STEP 已被导入为展开的世界几何时，不能仅凭实体位置一致就声称恢复了原装配层级。

## 7. 草图、数值与拓扑

沿用 readable v3 的安全底线：

- float 使用可往返的表达；不得为美观统一截断小数或把微小非零值归零。
- 长度统一为 mm，角度单位明确。导入时应记录原文件单位证据及所用转换，未知信息保留 unknown。
- 准备层只做有界调整；每次端点、坐标架或派生几何调整记录原值、目标值、容差及理由。
- 同一 loop 内按明确拓扑关系复用点；不同 loop 不按坐标接近自动合并。
- 保留明确的 region / outer / holes 关系，emitter 不重新推断孔归属。
- 至少三条直线且满足端点与身份条件时，可通过 `_add_closed_polyline()` 输出有序闭合折线；混合线弧保留显式调用。

任何近似曲线、离散拟合或拓扑修复都需要单独的能力和误差契约，不能静默加入。0.3.0 的 `verified-kernel-meridian-v1` 允许重放内核求交返回的有界 B 样条截面，约束如下：

- 仅用于已找到候选旋转轴的半边轴截面，不据此宣称支持通用样条拉伸或任意曲面。
- 保留裁剪后的控制点、degree、knots、multiplicities、weights、periodic；转换器不采样、不拟合、不量化这些数据。
- 控制点到截面平面的残差不得超过 length_tolerance（默认 1e-6 mm），逐曲线记录实际残差和来源。
- 双向 Cut 前允许用 bbox 和体积作提前拒绝：当前 bbox 阈值为 max(100 × length_tolerance, 0.001 × 源 bbox 对角线)，体积相对误差阈值为 0.001；只能拒绝候选，不能据此接受。
- 内核求交本身可能使用近似表示，必须明确记录；旋转候选与源实体双向 Cut 的相对差异仍不大于 1e-7，实际生成代码仍需逐实体、STEP 回读及 CD/IoU/V 验收。
- 截面曲线来自派生求交结果，使用 section_edge_index，不冒充原始 STEP 的 source_edge_index。
- 闭合圆可用两段解析半圆弧表示；此表示写入 preparation，不是多边形离散化。

## 8. 受控模板复用与结构识别

模板复用用于减少重复实现，不等于恢复了共享设计参数或原始阵列。

允许复用需要同时满足：操作类型、依赖拓扑、轮廓拓扑及参数绑定方式一致；每个实例保留尺寸和定位参数；每次调用独立创建几何；默认参数下每个实例和完整模型均有相应验证证据。

- 模板共享与参数共享分别决策。共享工厂可以接收多个相互独立、默认值相等的半径。
- 同一工厂对多个显式实例的循环是代码复用，不能在元数据中标记为原始 pattern。
- 矩形、圆环、阵列或镜像等语义识别只能发生在识别/计划层；新增类别需要独立证据、实现和回归。仅检测到重复，不足以授权参数联动。
- 不要求为了复用强行抽象；不以函数数、行数或 token 数作为几何通过条件。

## 9. 几何验收

### 9.1 默认口径

默认采用 `fixed-frame-shape-v1`，保留原始尺寸及世界位置。比较双方实体空间并集；只可使用施加于双方的同一个数值条件化变换。

| 必需指标 | 定义 | 阈值 |
|---|---|---|
| CD | 面积加权表面采样的双向平均最近邻距离，除以参考特征长度 L | `CD / L <= 0.01` |
| IoU | BREP 空间交集体积 / 并集体积 | `>= 0.999` |
| V | `abs(V_candidate - V_reference) / V_reference` | `<= 0.001` |

`L = sqrt(6 × trace(参考形状中心惯性张量) / V_reference)`。默认每个形状 8192 点，seed=0，线性网格偏差为 `0.001 × L`；另保存双向平方距离均值之和 CD²。记录采样、网格、单位、协议版本和依赖版本。采样 CD 是近似证据，几何相同也不保证采样 CD 为零。

IoU 布尔失败、无效结果、非有限值或不可信数值不能作为 IoU=0 或通过；沿用现有双向 Cut 可靠性核查。微小越界保留原值及核查结果，不直接截断成 1。不得以 CD 替代缺失的 IoU。

只有显式选择时，才使用现有 `similarity-shape-v4` 的整体等比缩放、正规旋转和位移验收。两种协议必须分组报告，不得合并成一个未注明口径的通过率。

### 9.2 必需验证路径

1. 实际执行 `build()`，提取返回值；检查拓扑、闭合实体及正有限体积。
2. 导出 STEP，回读并检查有效性。
3. 内存模型与回读模型始终按 world 口径核查，防止导出改变模型。
4. 原始源参考与回读候选按所选协议执行 CD、IoU、V。
5. 核对源几何覆盖映射；不能利用整体并集指标掩盖静默跳过的源实体。

全局空间并集指标可能无法区分装配结构差异或检出极小局部缺失。实体/实例对应、局部诊断及装配结构评价需单独记录，不通过改变全局指标名称解决。

## 10. 验证分层与训练状态

必须分别表达以下证据；字段缺失不得解释为通过：

| 字段 | 值与含义 |
|---|---|
| `geometry_validated` | `true`：几何路径完整通过；`false`：确认失败；`null`：证据不足 |
| `parameter_edit_validation.status` | `not_run` / `partial` / `pass` / `fail`，附具体参数和测试值 |
| `assembly_validation.status` | `not_run` / `unsupported` / `pass` / `fail`，附所验证的结构范围 |
| `history_recovered` | 无独立历史证据时为 `false` |

参数编辑结果只适用于已记录的有限测试，不是对任意尺寸或整个参数区间的有效性保证。测试至少检查实际重新 build、拓扑有效性、对应参数是否生效及已声明的解析变化关系。部分参数通过不能写成所有参数都通过。

`train_ready` 仍可用于已声明的 **geometry_reconstruction** 任务，但要求代码、几何、源覆盖及必需度量证据完整。参数编辑或装配训练还需满足该任务的额外条件；不得用几何通过证明历史恢复或设计参数真实性。

状态规则保持证据优先：

- `rejected`：确认的代码/构建错误、无效候选导出或可靠测量下的几何不匹配。
- `provisional`：识别不支持、参考不可用、必需测量不可信、超时或进程异常。
- `train_ready`：所声明任务的全部必需证据通过。

结构指标和压缩率是审阅信息，不授予通过状态。

## 11. 元数据与产物

延续当前文件布局：`model.scapi.py`、`model.ir.json`、`model.prepared.ir.json`、`model.symbols.json`、`model.step`、`report.json`，以及 run 级 summary。

采用新协议时，至少增加以下分离的版本与来源信息：

- `code_structure_spec = "step-readable-v1"`，同时保留实际 emitter 的 `readable_version`；不得把它与 IR、识别器或度量版本混用。
- 源文件 SHA256、导入单位/变换证据、源实体/面/边索引。
- 重建操作依赖、源覆盖映射、候选选择、接受及拒绝证据。
- 参数来源、编辑策略、绑定和依赖；局部坐标架及定位映射。
- 模板定义、逐实例参数和定位；是否只是代码复用，是否存在设计关联证据。
- 几何、编辑、装配及历史的独立评价；训练任务声明。
- 函数数、主函数长度、模板/实例数、独立参数数等结构信息。

详细证据可放在旁置 JSON，生成代码只保留帮助理解操作与参数的简短说明。不得在代码中写入机器路径、运行耗时或其他不必要的环境信息。

## 12. 回归与启用门槛

启用 `step-readable-v1` 前需要以下证据，不能仅重标已有 report：

1. 保留当前可重建几何与真实 ABC 回归，检查默认模型和执行结果。
2. 检查源码只依赖 simplecadapi，并在隔离导入下 build；重复 build 创建独立对象。
3. 检查源覆盖、命名、确定性、profile/feature/body/build 层次及显式参数绑定。
4. 检查独立等值参数、依赖参数、形状/定位分离及所公开参数的编辑案例。
5. 若启用模板，覆盖同构不同尺寸、不同位置、独立等值参数和多实例状态污染。
6. 检查单位转换、坐标架变换仅应用一次，以及 world 下平移和缩放错误被拒绝。
7. 检查必需度量错误、无效输出、超时、原生进程异常和不支持实体不会获得通过。
8. 至少审阅 10 个不同结构样例；阅读性检查不能代替 CD、IoU、V。

## 13. 当前实现与能力边界

| 要求 | 0.4.0 实现 | 边界 |
|---|---|---|
| 独立代码、profile/feature/build、BODIES | 纯拉伸沿用 STEP emitter，含旋转/CSG 使用组合 emitter；仅导入 simplecadapi | 每源实体对应一个完整重建根；可为拉伸、旋转或有界 CSG；内部操作保留显式依赖 |
| 重建证据、依赖及覆盖 | 源实体→重建操作→输出实体映射；源面/边索引及派生截面、残余体与分区来源；逐实体双向 Cut | 不支持任一实体时整例 provisional；记录部分识别进度但不输出部分通过模型 |
| 拉伸距离来源 | 优先平行端面距离，V/A 回退明确 derived | 不将 V/A 当独立体积证明 |
| 旋转识别 | 解析曲面轴候选、必要同轴/法向筛选、半边轴截面、完整旋转及源差异核查 | 仅完整 360°；不从一个截面推定任意非轴对称模型 |
| 轴截面几何 | 直线、圆/弧及有界内核 B 样条重放；固定几何来源记录 | 不进行转换器采样拟合；明确内核求交精度，仍通过所有几何门槛 |
| 参数与定位 | 拉伸独立尺寸、旋转/CSG 均匀 PROFILE_SCALE、独立 origin/x_axis/y_axis | 旋转/CSG 尚不自动推断独立原始半径/高度；局部控制点和节点固定，不冒充设计尺寸 |
| 受控模板 | 纯拉伸模型仍按准备草图 AST 完全匹配复用 | 混合路径逐实体明确生成，不跨不同操作强制抽象或推定阵列 |
| 格式与准备 | 纯拉伸 CAD IR 0.1；含旋转/CSG 为 step-reconstruction-plan-v1；逐操作准备协议 | 不修改上游 CAD IR 或 DeepCAD emitter 的能力声明 |
| 验收分层 | geometry、edit、assembly、history 和训练任务独立；保留所有阈值 | 普通转换 edit=not_run；回归只做有限编辑，成功为 partial；assembly=unsupported |
| 回归 | 44 项 unittest；4 个混合能力样例及既有旋转样例；同一 ABC 前 20 例及旧版 SHA256/状态对比 | 非全量数据集；详见 [CSG 混合验证](../CSG_V4_VALIDATION.md) |
| CSG 与分区 | 有限解析工具体、草图拉伸、残余体识别及平面分区组合 | 仍不支持无界布尔搜索、任意旋转角、通用样条拉伸与一般自由曲面分解 |

新产物写入 `code_structure_spec=step-readable-v1`。纯拉伸的 readable_version=3；组合 emitter 的 readable_version=null、shared_readable_version=3，并明确自己的 emitter 标识。IR/计划、识别器、准备和度量协议分别记录，不将新操作伪标为 readable v3 的既有能力。历史产物和旧验证记录不重标。几何通过只授予 geometry_reconstruction 的 train_ready，不自动授予参数编辑、装配或历史恢复任务的通过。

## 14. 有界 CSG 重建契约（0.4.0）

CSG 是 STEP 专用重建计划的独立能力；纯拉伸仍为 CAD IR 0.1，含旋转或 CSG 使用 step-reconstruction-plan-v1。不得把 feature.csg 冒充上游 CAD IR 已支持的指令。

- 优先保留已有拉伸与完整旋转结果。CSG 只在两者无法重建当前源实体时尝试；能力判断以完整源实体为单位。
- 主体候选来自实际平面端面轮廓的拉伸，或由包围盒构造的显式矩形拉伸；工具体来自有限解析平面、圆柱、圆锥、球、圆环。主体和工具体须生成真实 SCAPI 几何，不得读入源 STEP 或内嵌 BREP。
- 主体包围验证、累计切削缺失验证与最终双向 Cut 分开记录。局部切削不得累计删除超过当前约束的源体积；任何中间检查都不能代替最终对称差 ≤ 1e-7 的完整重建验证。
- 补料/去料残余体只在能独立识别成受支持拉伸或旋转时生成操作；不允许把任意剩余 BREP 直接包装成常量。
- 源平面分区后的每个局部体分别识别，分区组合覆盖须通过检查。停止前任一局部体不支持，整例仍不具备完整通过资格。最终实际代码仍须通过逐源实体、回读及 CD/IoU/V。
- 派生残余体使用 derived_residual / residual_edge_index；分区使用 derived_partition / partition_edge_index / partition_face_index。不将局部编号伪写为原始源实体编号。
- recipe 是确定的有向无环图；拒绝缺失节点、环、未知操作和未使用节点。cut/intersect 为二元，union 可为多元，关联并集合并后再回放；不能为连接分离体而人为加桥或扩大容差。
- 每个源实体公开独立 PROFILE_SCALE 和 origin/x_axis/y_axis。scale 对主体、工具体及其相对位置共同作用，正值均匀缩放的期望体积比为 s³；固定局部截面和工具尺寸不声称恢复了独立原始设计参数。
- 草图外环与孔的输入方向使用解析线/弧的有向面积规范化，适配 SCAPI 对内环自动反向的接口行为；不移动曲线上的点、不采样拟合形状。
- 默认每次直接搜索最多 96 个候选；每源实体重建计划最多 32 次二元等价布尔操作；直接搜索边界最多 80 面；分区最多 24 个局部体尝试、深度最多 3。15 秒为协作式识别预算，原生调用由整例子进程 timeout 最终约束。预算耗尽不表示数学上无解。
- source_coverage 仍映射每个原始实体的完整重建根操作 solid_NN_csg 到真实返回 body；内部工具、分区和局部体不冒充源装配实例。history_recovered=false、assembly_validation=unsupported 独立保留。

实测结果及限制见 [CSG 混合验证](../CSG_V4_VALIDATION.md)。
