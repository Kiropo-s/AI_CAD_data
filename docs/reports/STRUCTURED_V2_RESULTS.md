# 可读代码 v2 阶段验收（2026-10-23）

## 实现

可读版从继承保真 emitter 并替换字符串，改为内部 `CodePlan` 和独立结构化 emitter。生成脚本使用顶部参数、profile 函数、连续源特征函数和显式 `build()`，只依赖 SCAPI。折线辅助函数及装配函数包含在脚本内。公共 IR 仍为 v0.1 草案。

IR 规范、Schema 和校验器补齐可选来源字段及 profile 序号规则；缺失来源仍可建模。源特征分组不合并布尔，等值独立尺寸不共享。可读元数据和训练导出标记版本 2。

## 限制与下一阶段

本阶段提升主流程层次和追溯明确性，总代码量反而增加。`00000069` 的最长函数仍为 85 行：同一源特征内多个 profile 继续显式保留各次拉伸和布尔。未据此宣称训练效果改善。

后续适合单独评估特征内部重复代码的表达方式、训练 token 成本及参数编辑有效率；几何度量不可靠的样本需要专项诊断。形状识别、阵列/镜像及设计约束推断不在本轮实现中。
