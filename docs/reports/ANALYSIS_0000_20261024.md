## 3. 最主要的拦截项

### 3.1 源 bbox 冲突：176 例

这 176 例的候选与参考几何比较已经通过，仅顶层 JSON 的 bbox 与参考不符。bbox 相对误差中位数 0.3931，最大 1.1099，不是普遍的浮点边界问题。

使用相对源最大跨度 1e-6 的包含判断，156 例源 bbox 包含参考、11 例参考包含源 bbox、9 例双方均不包含；本组未记录参考 frame 修复。

例如 00000447 的源 bbox 为约 [-25,-25,0,25,25,73.485] mm，参考为 [-6.35,-6.35,0,6.35,6.35,25.4] mm；源序列只有一次 25.4 mm 拉伸。00000349 的源最大 z 为 25.4 mm，参考为 22.225 mm。这说明源属性与所重建序列之间存在冲突；不能仅据日志判断是属性过期、源序列不完整还是重建遗漏。

建议单设 source_evidence_conflict 诊断分类，并抽查 00000447、00000349、00000508、00000393。保留当前入库门槛，先确定顶层 bbox 的语义和可靠性，不直接取消 bbox 检查。

### 3.2 度量异常：122 例

| 原因 | 数量 |
| --- | ---: |
| 交集体积不一致 | 68 |
| shape contains no solids | 36 |
| 双向差集无效 | 12 |
| 交集拓扑无效 | 5 |
| 候选 STEP 回读无效（00007271） | 1 |

当前 volume_iou 仍用固定 1e-6 mm³ 判断交集体积超出输入体积。68 例中有 12 例超出比例 <= 1e-12、35 例 <= 1e-8，但也有严重异常：00002722 超出约 4.535%、00002547 约 0.04925%。这些不能全部归为浮点噪声。

交集为空时当前 _intersection_volume 调用要求含 solid 的 volume()，无法正常返回 0。36 个 no-solids 报错需要在重建后区分合法空交集、零体积交集和无效输入，不可批量认定它们可通过。

建议先修合法空交集、增加与尺度相关的数值一致性检查、保留原始交集值，并区分数值错误与几何不匹配。数值容差不替代验收阈值。compare_shapes 中途抛错会丢掉此前已计算的体积/面积/bbox，应增量保存这些指标。00007271 应单列为候选导出/回读问题，不宜笼统归为测量问题。

### 3.3 完整几何比较不通过：56 例

下列指标统计可重叠：实体数 46、面积 47、IoU 22、差集 18、体积 9、CD 6、世界 bbox 0。29 例只在实体数和/或面积上失败。

这提示 NewBody/融合、内部面和实体组织是重要诊断方向，但尚未逐例证实根因。不要用占据体积近似相等替代实体组织等价。代表样本：00000137、00000729、00001982（实体数+面积），00005666（仅实体数），00003149/00004236（IoU+差集），00005699（多项不匹配）。

### 3.4 adapter 与构建

96 个 adapter 拒绝：68 无有效拉伸、21 empty_profiles 导致不完整 IR、2 缺前置 body、2 轮廓接触、1 重叠、1 非平面（00007714）、1 无法闭合（00007729）。不应仅为提高通过率静默补齐或跳过源特征。

17 个构建失败：13 布尔拓扑无效、3 特征执行后无 body 可供后续操作、1 草图成面失败。优先保存 00004520、00009831、00006295、00007529 的逐步结果进行诊断。

11 个参考错误：4 重建拓扑无效、6 STEP 回读拓扑无效、1 STEP 回读失败。继续隔离，不生成假真值。00009664 的退出码等于 0xC0000005，符合原生进程访问异常的表现，具体崩溃位置未知，需单例隔离并保留故障产物。
