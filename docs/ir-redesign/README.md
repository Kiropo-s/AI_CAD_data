# 基于 ABC 100 例的 STEP 计划重构

日期：2026-10-26。状态：设计稿，可作为实施任务依据；本目录不表示新编译器已实现。本次仅新增设计和审计文件，没有修改运行中的转换器、既有报告、原始 STEP 或 json2scapi。

## 决策

选择一次不兼容的 STEP 专用重构：新运行只接受 `format="step-plan"`、整数 `version=1`。未来 step2code 主版本进入 1.0。历史 CAD IR 0.1 和 step-reconstruction-plan-v1 只作为只读基线，不实现生产加载器、自动迁移器、旧 emitter 适配或旧参数名兼容。

不再在旧字典上修补旋转/CSG 例外；采用独立类型模型、一个显式有向无环图、逐输出实体根、独立几何准备与执行、单一可读 SCAPI 后端。识别算法先迁移现有有效能力；结构重构和覆盖率扩展分开验收。

“彻底”指消除旧格式和执行语义的牵连，不是重写已验证的所有几何数学。导入单位处理、可靠度量、算法原理、有效夹具与边界测试应迁移，并用新契约复核。保留旧产物，不要求新代码继续读它们。

## 必须做出的取舍

- 一个新格式，纯拉伸也使用它；不再按是否包含 CSG 切换数据语义。
- 输出实体显式，取消线性序列的隐式 body 累积和“最后一个 results 代表所有实体”。
- 一个节点引用系统；取消 recipe 子图、feature_id/profile_id 隐藏引用及泛字符串递归重命名。
- 执行只需要 plan，不需要原 STEP、evidence 或 symbols；来源只影响审计，不能决定执行顺序或坐标。
- 独立 STEP 几何准备；不再通过 DeepCAD prepare_ir 决定原生 STEP 轮廓是否可接受。
- 识别器、原生重放器、SCAPI 编译器、验收器分离。识别的原生缓存不得成为最终 plan 的隐藏必需状态。
- 代码、IR 和参数不再字节兼容旧版；保留几何、来源真实性和可编辑性要求。
- 所有模糊失败拆成结构化 reason_code。预算耗尽、能力不覆盖、无效源几何、原生调用错误和确定的几何不一致不能混用。

## 重构完成标准

28 个历史成功输入在新流程保留完整默认几何通过；5 个导入失败不因静默修复或丢弃几何变成成功；2 个失败用例有独立可复现和可定位原因。62 和 52 的问题不预先宣布已修复；根因未确定前必须保留失败/不确定状态。

新 loader 能拒绝错误版本、缺失输出、坏引用和类型错误；去掉原 STEP/evidence/symbols 后仍可从 plan 重新执行、编译独立代码；程序仅导入 simplecadapi。搜索停在第 N 个实体时，前面完成的候选和验证证据不会丢失，整例仍保持 incomplete。

本次结构重构不承诺解决剩余 63 个识别不足；它必须让这些不足有准确可比较的原因，并让后续策略可独立接入。
