# 0.4.0 占据前瞻搜索验证

日期：2026-10-26。默认模式 lookahead，保留 guided 与 legacy。仍为独立 STEP→SCAPI 路线，未使用 CAD IR、源几何嵌入或运行时指令解释器。

## 修改内容

- 失败的直线拉伸保留少量接近的、可用原生轮廓重建的候选。只保留原已计算且 bbox 匹配的候选，不用近似误差放宽接受标准。
- 在确定性占据采样上规划短操作链，使用 bitset 快速组合、有限束宽和多样性。默认近似束宽 48（beam 参数×16），每个采样 mask 有限保留 3 个构造，深度仍不超过 8。每步允许有限采样误差退步；不能将其解读为精确体积误差。
- 最多取 40 个候选序列，用真实 OCC 布尔构造及精确最终差分确认。公共前缀和失败前缀缓存以操作序列为键；没有把相同采样 mask 认定为相同精确几何。
- 先尝试高优先级单基本体，避免将球等简单解替换为影响参数编辑的多余裁剪。
- 阶段最多使用布尔次数上限的一半及配置时间额度的 35%，随后回到 guided；总软预算与总布尔次数上限不增加。单个原生调用仍可能超出软预算。
- 所有搜索布尔运算在 Build 前设置 NonDestructive，保护被多个分支复用的输入。该设置也用于本版 guided/legacy 对照。
- 精确评分按持有强引用的几何对象身份缓存，避免对象 id 被回收后误用。

未增加样条/椭圆、一般旋转体、自由曲面、圆角特征恢复或连续参数优化能力。环面组合偶然能表达部分圆角，不能视为通用圆角支持。仍只验默认参数；history_recovered=false。

## 测试

42 项 unittest 通过，日志：[unittest-lookahead-v04-final-42.log](../out/unittest-lookahead-v04-final-42.log)。

新增覆盖带偏心孔的环面圆角构造、近似占据假匹配不得通过、接近拉伸候选传递、共享布尔输入在构造和评分前后 BREP 序列化一致，以及可以跨越采样误差持平的短序列。CLI 的三个模式均在真实 worker 中验证。另新增报告临时共享锁的重试，以及持续锁定时有限退出并保留上一份有效报告的测试。

## ABC 对照

固定首 20 个输入；world 模式、8192 点、每源实体 20 秒软预算、256 次布尔尝试、8 步深度、束宽参数 3、每案例 120 秒 worker 硬超时。lookahead 的采样规划束宽与 guided 的精确队列宽度不同，这正是实验变更之一；不能声称计算步骤完全相同。

验收不变：逐实体相对对称差 ≤1e-7，代码真实 build，STEP 导出回读，CD/L≤0.01、IoU≥0.999、相对体积误差≤0.001。全部输入记录，不挑选成功案例。

原 0.3.0 对照中 guided 与 legacy 均为 6/20。0.4.0 对照将重跑当前 guided 和 lookahead，避免把新启用的 NonDestructive 或运行时差异误归因于前瞻搜索。

00000006 的保留拉伸候选虽曾得到约 0.88% 的历史误差，但在当前双向差分与独立积分一致性检查中失败；保留候选不等于允许接受不可靠几何。

两种模式的输入 SHA256、运行时、评估器、几何/候选/搜索/生成源码及配置预算一致（搜索模式参数除外）。lookahead 模式还启用保留接近的原生拉伸候选；这不是仅单一剪枝参数的消融实验。

## 报告写入异常和审计说明

lookahead 原始整批运行记录为 6 个通过、13 个 provisional、1 个 rejected。00000016 在识别阶段受到 Windows 临时文件替换访问拒绝影响，未进入最终几何验收。随后只在 pipeline.write_json 内增加有限短重试（6 次替换，最多 5 次短等待），几何计算和判定未改动；按原预算重跑该输入，完整通过。

审计后的汇总替换该项并链接其新 report；原始汇总和失败 report 保留，替换策略与前后条目都写入 summary.audit。未对几何失败案例按成功结果挑选重跑。guided 的部分案例也使用报告重试修复后的 writer。

因此 **所有文件的完整 pipeline.py 哈希并不完全相同**。审计分别记录两个报告实现哈希，并用 AST 核对变化仅限 write_json；其余几何相关源码指纹和依赖全部一致。对照标记 same_implementation=false、same_geometry_implementation=true，不把整个运行描述成字节级完全相同。

## 新成功案例 00000016

模型含 3 个源实体：第 1 个用单次拉伸；第 2 个通过 guided 回退得到 5 步 CSG；第 3 个通过占据前瞻找到 4 步 CSG。第 3 个实体的方案为环体起点，依次并圆柱、并拉伸体、切偏心圆柱孔、并拉伸体。

该例在当前 guided 对照中已通过前 2 个实体，但第 3 个在 256 次尝试后仍失败；lookahead 对第 3 个实体用了 4 次真实布尔构造并精确验收通过。不能把这一例的减少推广成全部模型提速。

| 验证 | 结果 |
| --- | ---: |
| 逐源实体相对对称差 | 三个均为 0 |
| CD/L | 0.005948494906191002 |
| 体积 IoU，原始值 | 1.0000000001468468 |
| 相对体积误差 | 2.8389281157633414e-12 |

IoU 的微小超过 1 沿用共享评估器数值可靠性规则，不人为裁剪。代码只导入 simplecadapi，已在 Python -I 隔离进程中重复 build，均新建 3 个实体；独立核查记录保留于 abc-case16-lookahead-v04-report-retry/standalone-check.json。

## 成本与限制

本机 worker 时长累计：guided 329.06 秒，审计后 lookahead 424.68 秒；中位数分别为 19.76 和 21.93 秒。lookahead 在 00000014 重建前 2 个实体后，第 3 个实体的精确评分累计约 101.52 秒，整件约 106.50 秒后以软预算耗尽结束，未触发 120 秒 worker 硬超时；guided 则在第 1 个实体提前失败。这一差别显著影响总时长。没有整体提速结论，单次 OCC 调用的阻塞仍未解决。

其余 13 例仍未获得完整已验证方案：11 例达到软时间预算，1 例达到布尔尝试上限，1 例在当前回退约束内无解。预算耗尽不能证明不可重建。采样可能遗漏薄壁、孔和局部细节；短序列束宽及候选几何表达仍有限；样条/一般旋转等缺失能力未补齐。后续需在独立分层样本上验证收益。
